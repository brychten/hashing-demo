Caché de consultas SQL
con tabla hash

Tabla hash con open addressing y sondeo lineal (+1 circular). Cuando el slot calculado por MD5 está ocupado, se avanza circularmente hasta encontrar un slot libre. La búsqueda sigue el mismo recorrido.

Inserción y búsqueda con sondeo lineal
def insert(table, query, size): idx = int(md5(query), 16) % size # posición inicial for i in range(size): slot = (idx + i) % size # sondeo +1 circular if table[slot] is None: table[slot] = query # slot libre → insertar return slot raise Exception("Tabla llena") def search(table, query, size): idx = int(md5(query), 16) % size for i in range(size): slot = (idx + i) % size if table[slot] is None: return -1 # slot vacío → no está if table[slot] == query: return slot # encontrado
